04 · 图像处理

Fourier filtering 与 rolling-ball 校正

以下设置会独立应用到每个参与处理的波数和 pattern，输入均为原始 on-MS 反射率裁剪图。

Fourier filtering

每行或分号分隔一对坐标。对称频率自动添加。

单位 cycles/pixel，表示幅度保留 50% 的椭圆半轴。值越小，该方向平滑越强；相等时为圆形。

Rolling-ball 平场校正

校正 = Fourier 后反射率 × 背景中位数 / 估计背景。空间半径宜大于要保留的特征；更大的半径会增加计算时间。

裁剪图频谱

横向 fx，纵向 fy。中心为零频；点击亮峰添加陷波点。加窗仅帮助检查，不改变处理数据。

06 · 比较与量化

六阶段对比与 CNR

每个波数独立定色阶。三张反射率图共用范围，两张吸光度图共用范围，raw 强度单独显示。

在任意阶段拖动画框，所有阶段同步显示。

CNR = |目标均值 − 背景均值| / 背景标准差（ddof=1）。使用各阶段共同有效像素；无效值不置零。平滑可能提高 CNR，也可能损失细节。
