04 · IMAGE PROCESSING

Fourier filtering and rolling-ball correction

Settings apply independently to every involved wavenumber and pattern using the original on-MS reflectance crop.

Fourier filtering

Separate coordinate pairs by lines or semicolons. Symmetric frequencies are added automatically.

Units are cycles/pixel and represent the half-amplitude ellipse axes. Smaller values smooth more strongly along that axis; equal values produce a circle.

Rolling-ball flat-field correction

Correction = post-Fourier reflectance × median background / estimated background. Larger radii take longer.

06 · BASELINE CORRECTION

Baseline correction

Fit the configured reference bands at each pixel and subtract the fitted baseline from each center band. Two references interpolate; more use unweighted linear least squares.

Absorbance before and after baseline correction

Inspect a pixel's baseline correction

Choose any processed pattern and center band. Click the absorbance image or enter a pixel coordinate. Coordinates are zero-based and local to the on-MS crop (x = column, y = row).

Absorbance before baseline · click a pixel

Only the selected reference bands enter the fit. The center band is excluded. The corrected center absorbance equals its original absorbance minus the fitted baseline at that wavenumber.

07 · COMPARISON AND QUANTIFICATION

Six-stage comparison, CNR

Each wavenumber has its own scale. Reflectance stages share a range, absorbance stages share a range, and raw intensity is shown separately.

Drag a box on any stage; it is shown on every stage.

As = target mean; Abg = background mean; σbg = background sample standard deviation (ddof=1). CNR = |As − Abg| / σbg. Common valid pixels across stages are used; invalid values are not replaced with zero. Smoothing may increase CNR but can reduce detail.
