QCL · Multi-folder comparison

Add a dataset

Choose a data folder, all required CSV bands from one pattern, or one or more project ZIPs. A multi-dataset ZIP creates one tab per dataset. ZIPs are reproduced using their saved parameters; sharing conflicts must be resolved before final comparison.

Add folders, then switch tabs within each processing section. Each folder has independent ROIs and color scales.

Compare folders

Complete sections 2–8 and calculate CNR in each dataset tab. Each folder uses its own pattern. Colorbars are independent by default, with optional same-stage sharing across folders; the image stage and wavenumber are shared.

Automatic limits use the minimum and maximum of the selected stage, wavenumber and pattern in each compared folder. Enter absolute limits to override. Other processing stages remain independent; CNR values are unchanged.
