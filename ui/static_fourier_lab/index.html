01 / SOURCE

Make an image

Gaussian smoothing before noise. Larger σ makes a wider grayscale edge transition; 0 preserves the current edge. Independent of corner rounding. Strong smoothing can soften narrow strokes and lower their peak intensity.

Letters use geometric centerlines with a constant stroke width. Rounding curves the corners and rounds the open ends; adjacent segments limit the rounding distance.

PNG, JPEG, TIFF, BMP or headerless CSV. 8–1024 pixels per axis; up to 8 MB. Color images become grayscale [0,1]; numeric TIFF / CSV values are preserved. Transparent pixels use white.

Choose what passes

One pair per line. Click the input FFT to add a center. Its symmetric partner is automatic.

Lower cutoffs smooth more detail. The input mean is preserved. Notches can remove real structure as well as noise.

FOURIER DOMAIN

Where the frequencies go

log(1 + |FFT|), shared scale. Center = DC. Click the input FFT to place paired notches.

All FFTs use the actual filtering grid, including reflection padding, without a Hann inspection window. FFT after filtering is before the final spatial mean restoration. Vertical frequency increases downward; units are cycles/pixel, not optical wavenumbers.
