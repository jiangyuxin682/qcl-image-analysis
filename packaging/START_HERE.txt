QCL Processing Workbench documentation
======================================

The supported user setup is Fork -> Clone -> install Python 3.12 in the
terminal -> create .venv -> install dependencies -> launch.

Repository: https://github.com/jiangyuxin682/qcl-image-analysis
Open ui/INSTALLATION.md in the repository for Windows and macOS commands.
Open ui/QUICKSTART.md for the processing workflow, exports and reproduction.

This file is retained as an internal packaging resource. The user guide does
not require a prebuilt executable or build-kit archive.
