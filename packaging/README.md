# Internal packaging tooling

User installation and updates follow the single
[Fork/Clone terminal guide](../ui/INSTALLATION.md) on Windows and macOS.
No prebuilt application or build-kit download is required or advertised.

This directory retains internal build tooling used by the Windows CI workflow:
`build_windows.ps1`, `windows.spec`, dependency declarations, notices, and runtime
checks. These are maintenance assets, not another user installation procedure.
`START_HERE.txt` is a build resource that points readers to the current guide.
Source changes do not establish that an executable has been built or validated.
